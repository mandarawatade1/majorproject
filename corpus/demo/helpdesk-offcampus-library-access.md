## How off-campus access works

Subscribed journals and databases are licensed to the institute by network
address. On campus, the publisher recognises the campus network and grants
access. Off campus, your home address means nothing to the publisher, so
requests go through the institute's proxy, which presents them as coming from
the campus.

This is why the same link works on campus and fails at home: nothing is broken,
the request simply arrived without institutional identity.

## Use the right link

Access must start from the library resource page, not from a link copied out of
a search engine or a colleague's message. A direct publisher link bypasses the
proxy and will ask you to pay.

If you have a direct link you need, find the same item through the library
resource page rather than trying to make the direct link work.

## When you are asked to log in

The proxy asks for your institutional account — the same credentials as the
portal and Wi-Fi. If those fail, the problem is the account, not the library.
See DEMO/HELP/PORTAL/2026/02.

You should never be asked for a payment card. If a page asks you to pay, you
have reached the publisher directly rather than through the proxy. Go back to
the library resource page.

## What off-campus access does not include

- Print holdings, obviously
- Resources the institute does not subscribe to, which will show an abstract and
  a price
- Some publishers restrict a title to on-campus use only, in which case the
  library resource page says so against that title

A title that is not subscribed is a purchase decision for the library, not a
fault. Suggest it through the library requisition form.

## Bulk downloading

Automated or bulk downloading of articles breaches every publisher licence the
institute holds, and publishers detect it by request rate. A detected breach
suspends access **for the whole institute**, not for the individual. Download
what you need to read.

## During campus network maintenance

The proxy runs on the campus network, so off-campus access to subscribed
resources is unavailable during a maintenance window — see DEMO/IT/2026/02.
Institutional email is unaffected, as it is externally hosted.

## Raising a ticket

Include: the resource name, the exact URL you started from, whether you began at
the library resource page, whether you were asked to log in, and the exact
message shown. "Library not working" cannot be diagnosed; the starting URL
usually identifies the problem immediately.
